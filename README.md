# LexIndia

AI-powered legal assistant for Indian Law. Built for lawyers, businesses, and citizens who need affordable legal help.

Live: https://lex-india-three.vercel.app

---

## What it does

- Analyzes legal documents and detects risky clauses
- Answers questions about Indian Law in simple language
- Covers IPC, CrPC, GST, Property Law, Consumer Rights

---

## Tech Stack

- React.js + Vite
- Groq LLM API (Llama 3.3 70B)
- Vercel

---

## Getting Started

Clone the repo and install dependencies:

    git clone https://github.com/rupnawarpratik88/LexIndia.git
    cd LexIndia
    npm install
    npm run dev

Add your Groq API key in .env file:

    VITE_GROQ_API_KEY=your_key_here
